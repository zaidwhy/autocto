# AGENTS.md

This repository's agent instructions live in `CLAUDE.md`. Read it first: @CLAUDE.md

Rules for any agent (Codex, Gemini, Copilot, Claude): never write the em dash character (U+2014); never add AI attribution; never read or write `.env`, secrets or `.git/` internals; `git fetch origin` before every push and never force-push; never invent metrics, test counts or deploy URLs; read before editing, reproduce before fixing, run the tests before saying done. The definition of done and run commands are in CLAUDE.md.
