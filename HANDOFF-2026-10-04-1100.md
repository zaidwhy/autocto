# Handoff 2026-10-04 - real import resolution and the plan command

## Done (pushed to main, CI green)
- `src/autocto/imports.py` (standard library only): `resolve_imports(sources)` follows each import to the one file it names. Python via `ast` (packages, relative imports, `src/` layouts, `from pkg import submodule`); JS/TS relative specifiers, `index.*`, `.js` to `.ts`, `export ... from`, `require`, dynamic `import()`. `fan_in_from_graph` counts importers.
- `maintenance` fan-in and `architecture` (cycles, god files, layering) now use it. Two files with the same name no longer link or form a false cycle (regression test fails on the old code).
- `autocto plan FILE [--json]`: the migration planner from a JSON proposal; a bad proposal or a dependency cycle prints one `error:` line and exits 2.
- Fixed: `maintenance` returned no results on Windows (backslash paths against git's slashes); result paths are now forward-slash everywhere.
- 133 tests pass, ruff 0.16.9 clean. `extract_referenced_names`, `compute_fan_in`, `build_import_graph` remain for callers that only have bare names.
