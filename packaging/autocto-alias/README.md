# autocto (alias)

This package only points at **[repo-autocto](https://pypi.org/project/repo-autocto/)**, the published
name of [autocto](https://github.com/zaidwhy/autocto): repository-health analyzers from git history alone.

`pip install autocto` installs `repo-autocto` and gives you the `autocto` command. Prefer installing
`repo-autocto` directly:

```
pipx install repo-autocto
autocto report .
```
